# Razorpay Clone

A simple clone of the Razorpay website built using HTML and Tailwind CSS.

## Technologies Used
- HTML
- Tailwind CSS 3
- JavaScript

## Features
- Responsive design
- Navigation bar
- Modern UI

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Run Tailwind CSS:

   ```bash
   npm run dev
   ```

5. Open `index.html` in your browser.
